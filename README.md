## 10. Current Project Scope

This repository contains the complete Rossmann Store Sales Forecasting project, including:

- Data exploration and preprocessing notebooks.
- Sales and customer forecasting models.
- Model evaluation reports, tables, and visualizations.
- Interactive Streamlit dashboard.
- MLflow experiment tracking and model artifacts.
- DVC-based dataset and model versioning.

**Data and Model Management:**
- Dataset files are tracked using DVC and stored on DagsHub.
- Trained model files are tracked using DVC and stored on DagsHub.
- GitHub contains the project code and DVC tracking files.
- Python dependencies are documented in `requirements.txt`.
